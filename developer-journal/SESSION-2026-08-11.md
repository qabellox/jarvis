# Session 2026-08-11 — Distributed Refactor: The Core

## What I built
- Extracted the agent brain from the Electron main process into a standalone
  **JARVIS Core** service (`jarvis-core/`): AgentRuntime, DeepSeek SSE client, tool
  registry, ESP32 gateway, federated learning coordinator, memory store with local
  vector recall, SQLite (WASM) research database, WebSocket + REST servers, and
  autonomy loops (scheduler, proactive monitor, self-improvement, telemetry).
- Turned the Electron app into a **thin client**: `CoreClient` connects over WebSocket,
  IPC proxies every renderer channel to the Core. The cinematic UI is unchanged, plus a
  Core Online/Offline indicator and new Fleet/Memory/Tools tabs.
- Added the **Telegram bot** as a second client of the same Core.
- New tools: `execute_python`, `send_telegram_message`, `self_reflect` (kept all originals).

## Decisions & why
- **Core owns everything** — one source of truth; desktop and phone are interchangeable
  front-ends. This is the single most important architectural decision.
- **Separate ports** — ESP32 boards connect to `:8765`, clients to `:8767`, REST on
  `:8080`. (Caught an EADDRINUSE bug where both used the same port; moved the client WS
  port to 8767 because a system process (`svchost`) occupies 8766 on this machine.)
- **sql.js (WASM) instead of better-sqlite3** — zero native modules, so the DB works in
  Electron and Node with no ABI rebuilds or SSL-download risk. Swappable behind the
  `ResearchRepository` interface.
- **Local hashing embeddings for memory** — dependency-free vector recall; ChromaDB
  swappable later.
- **Demo responder without an API key** — runs the real tool pipeline, so the whole
  system is demonstrable end to end.

## Bugs & fixes
- `msedge-tts` exports `MsEdgeTTS` (not `EdgeTTS`); `toStream()` returns a Node Readable.
- DeepSeek/ws type issues: `WebSocket.OPEN` → numeric `1`; `RawData` imported as type.
- Auto-formatter occasionally dropped lines (constructor args, loop bodies, interface
  fields) — verified with `tsc` after every batch and rewrote affected files.
- Demo bridge had a class-property name clash (`federation` field vs method) — renamed
  to `federationData`.
- Hydration mismatch on the mic button — `micSupported` now set in an effect, not at render.
